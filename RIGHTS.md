## What is included

The code implements physical and signal-processing models.
Parameters are physical and design priors, published numerical measurements, or statistics fitted to recordings.
There are no soundfont maps, recorded samples, hardware ROM dumps, model weights, song scores or transcriptions.
The 909/Linn-style ROM buffers are generated by this library's own models.
CMUdict comes from the separately installed `cmudict` dependency, not a copied dictionary.
Python dependencies keep their upstream licences.

A fitted parameter file is a preset: one setting of a physical model, reached from some recordings.
The credits for each parameter set are in [`soundbench/instruments/models/PROVENANCE.toml`](soundbench/instruments/models/PROVENANCE.toml), and the recording-chain parameters have their own [notice](soundbench/instruments/rooms/PROVENANCE.md).
Some defaults were set against reference recordings that are not distributed or listed.

## Your own recordings

Fitting tools read explicit local files; whether you may use a recording is yours to check.
A fetch recipe isn't permission to redistribute a download, so keep audio and diagnostic output under the ignored `build/` directory.
