# Banjo fitting sources

The fitter accepts user-supplied isolated-note recordings; it doesn't distribute their audio.
Record source attribution, terms, checksums, crop windows and physical-string assumptions with each fit.

The included Philharmonia-derived parameter sets use the [Philharmonia Orchestra sound-samples collection](https://philharmonia.co.uk/resources/sound-samples/).
Its custom permission allows use including commercial musical works, but restricts making samples available as-is or as sampler instruments.
No source waveform enters the runtime instrument.
The recordings don't establish resonator construction, string material, pick type or physical-string assignments.

Parameter credits are in `soundbench/presets/PROVENANCE.toml`.
